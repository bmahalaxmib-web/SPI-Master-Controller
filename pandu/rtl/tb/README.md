# SPI Master Controller in Verilog

A synthesizable **8-bit SPI Master Controller** designed using Verilog HDL.

This project implements **SPI Mode 0 (CPOL = 0, CPHA = 0)** communication with configurable clock division. The design was verified using a Verilog testbench with a simulated SPI slave.

---

## Features

* Verilog HDL implementation
* SPI Master Controller
* SPI Mode 0
* CPOL = 0
* CPHA = 0
* 8-bit data transfer
* MSB-first transmission
* Configurable SPI clock divider
* Chip Select (`CS`) control
* MOSI and MISO support
* TX and RX shift registers
* `busy` status signal
* `done` transfer-complete signal
* Self-checking testbench
* Icarus Verilog simulation
* GTKWave waveform support

## SPI Signals

| Signal | Direction | Description          |
| ------ | --------- | -------------------- |
| `CS`   | Output    | Chip Select          |
| `SCLK` | Output    | SPI Clock            |
| `MOSI` | Output    | Master Out, Slave In |
| `MISO` | Input     | Master In, Slave Out |

### Control Signals

| Signal         | Description                   |
| -------------- | ----------------------------- |
| `clk`          | System clock                  |
| `rst`          | Active-high reset             |
| `start`        | Starts an SPI transfer        |
| `tx_data[7:0]` | Data to transmit              |
| `rx_data[7:0]` | Received data                 |
| `busy`         | High while transfer is active |
| `done`         | Indicates transfer completion |

## SPI Mode 0

This project uses **SPI Mode 0**:

```text
CPOL = 0
CPHA = 0
```

Therefore:

* SCLK is LOW when idle.
* Data is sampled on the rising edge.
* Data changes on the falling edge.
* Data is transmitted MSB first.

### SPI Timing

```text
CS    ───────┐                              ┌──────
             └──────────────────────────────┘

SCLK  ________/‾‾‾\____/‾‾‾\____/‾‾‾\____/‾‾‾\____

           ↑       ↑       ↑       ↑       ↑
         Sample  Sample  Sample  Sample  Sample

MISO      D7      D6      D5      D4      D3
```

## How It Works

When `start` is asserted, the SPI master begins a transfer.

### Step 1 — Chip Select

The controller pulls `CS` LOW.

```text
CS = 0
```

### Step 2 — Load Transmit Data

The 8-bit `tx_data` is loaded into the transmit shift register.

Example:

```text
TX DATA = 0xA5
```

Binary representation:

```text
10100101
```

### Step 3 — Transmit

The controller sends the data **MSB first**:

```text
1 → 0 → 1 → 0 → 0 → 1 → 0 → 1
```

### Step 4 — Receive

At each SPI clock rising edge, the master samples the `MISO` signal.

### Step 5 — Complete

After 8 bits:

* `CS` returns HIGH.
* `busy` becomes LOW.
* `done` becomes HIGH.
* Received data is available on `rx_data`.

## Example Transaction

The testbench sends:

```text
TX = 0xA5
```

The simulated SPI slave responds with:

```text
RX = 0x3C
```

Binary:

```text
TX = 1010 0101
RX = 0011 1100
```

Expected result:

```text
TX DATA = 0xA5
RX DATA = 0x3C
RESULT  = PASS
```

## Simulation

### Requirements

Install:

* Icarus Verilog
* GTKWave

### Compile

From the project root:

```bash
iverilog -o spi_sim rtl/spi_master.v tb/spi_master_tb.v
```

### Run

```bash
vvp spi_sim
```

### View Waveform

```bash
gtkwave spi_master.vcd
```
